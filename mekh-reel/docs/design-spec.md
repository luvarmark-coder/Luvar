# Mekh — Reels-ролик из портфолио (design spec)

Режим: **автономное творчество** (video-shotcraft, pipeline.md, этапы 0–7).
Источник: https://mehroj-dev.netlify.app — сайт-визитка и портфолио Mekh (сайты + AI-автоматизация, Дубай ⇄ Душанбе).

## Продуктовый бриф (этап 0)

| | |
|---|---|
| Что это | Портфолио разработчика: 6 главных кейсов в формате «Before / Now» + 8 дополнительных работ + NEURON (AI-автоматизация) + прайс |
| Зритель | Владельцы бизнеса (кафе, салоны, недвижимость, ателье, DJ-услуги) в Дубае и Душанбе |
| Задача видео | Чтобы после ролика владелец понял, **что сайт даёт бизнесу**: заявки сразу в WhatsApp, заказ без очереди, сайт на языке клиентов. Фокус — портфолио |
| Формат | Reels 1080×1920, 30 fps, ~41,6 с, русский язык |
| Ключевая идея | Сайт: «Большинство дизайнеров начинает сайт с дизайна. Я — с вашего бизнеса». Видео повторяет логику: не «красивые анимации», а **до → сейчас** для каждого бизнеса |
| Данные | Только публичные материалы самого портфолио (обложки, вторые экраны, мобильные скриншоты, миниатюры). Цифр/метрик не выдумано; тексты «До/Сейчас» — перевод строк Before/Now с сайта |

## Решение по материалу (Q1)

Живые сайты клиентов из облачной среды недоступны (сетевая политика), поэтому используются **реальные скриншоты, которые лежат на самом портфолио** (`assets/img/work/*`). Ничего не нарисовано заново. Единственные «ручные» элементы — маленькие виджеты-доказательства (поиск с опечаткой, шаги заказа и т. п.), они не копируют существующие страницы.

## Визуальный язык (токены сайта)

Фон `#081A13`, поверхность `#112B21`, текст `#EEECE1`, акцент «СЕЙЧАС» `#5EE3AC`, акцент «ДО» `#E8A84A`, линии `#22463A`.
Шрифты — собственные: **Mehr Display** (заголовки) и **Mehr Sans** (текст), оба поддерживают таджикскую кириллицу.
У каждого проекта — свой «цветовой мир» (из `--room-*` сайта): J/B `#0E0B24`, Velour `#E8D2C8`, Bil `#1A120B`, Ромашка `#EFE6D6`, Coffee Moose `#45B5A3`, TANDIS `#0A0B0A`. Нижняя панель «ДО/СЕЙЧАС» всегда фирменного тёмно-зелёного — связка с брендом.

Динамика: пресет «**премиум / спокойная уверенность**» — один голос на весь ролик: `blur-slide` (y + blur + opacity на одном прогрессе и одной кривой `quint-out`), смена кадров цветовой шторкой снизу (12 кадров), без тряски камеры (Q3), без групповых бликов (Q4).

## Музыка и ритм

`bgm-tech-house.mp3`, 124 BPM, сетка подогнана МНК (остаток ±19 мс). Видео-кадр 0 = такт 3 трека (t=7,289 с), поэтому **дроп трека падает ровно на бит 16** (кадр 232, измеренное смещение +25 мс = <1 кадра). Все границы шотов — на битах (`beatF(n)`), смена «ДО → СЕЙЧАС» — на бите 4 каждого кейса. Тяжёлых ударов всего два: дроп (бит 16) и приземление логотипа (R4: ≤3).

Структура кейса (116 кадров): шторка (0–12) → шапка + десктоп (4–40) → панель «ДО» (10–58) → смена на бите 4 → «СЕЙЧАС» + виджет-доказательство (58–116).

## Что не взято из библиотеки и почему

- `before-after-slider-scrub`: нужны два скриншота «до/после» одной вёрстки, а «до» у этих проектов — не сайт, а бизнес-боль (директ, очередь, фото-прайс). Заменено сменой чипа и цвета (янтарь → мята) — это язык самого сайта.
- `page-waterfall-wall`: подписи проектов должны читаться (названия работ — это содержание), а стена их размывает. Заменено сеткой с подписями и ускоряющимся входом.
- `flying-words`, `crash-zoom-punch`: слишком «игровая» энергия для премиум-пресета.

## Осознанные отступления от aesthetic-rules

- Q11: подписи к плиткам «ещё 8 проектов» — 32–34 px (минимум для вспомогательного текста), основные подписи/ДО/СЕЙЧАС — 58 px.
- R1: на финале wordmark держится ≥1 с; сама CTA-кнопка слегка «дышит» (±1,2 %) — это не бренд-знак.

## Звук

Таблица пинов `src/sfx.ts` (`SHOTS.x.from + offset`, без «голых» кадров): шторка → `swoosh-quick`, посадка карточки → `transition-soft`, смена на бите 4 → `transition-snap`, всплывающий виджет → `switch-tap` (реальный тумблер), сетка → `paper-move-quick` с убывающей громкостью, финал → riser → `impact-zoom-quick` → `shimmer-sparkle-sweep`. Две версии: с музыкой и без (SFX остаются).
