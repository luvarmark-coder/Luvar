OmniRoute-Kit: ярлыки для запуска OmniRoute и Chatbox
=====================================================

ЧТО ЭТО
  OmniRoute - программа-сервер на вашем компьютере (адрес http://localhost:20128).
  Через неё Chatbox общается с Grok (по вашему входу Grok Build).
  Набор запускает всё сам, вводить команды в PowerShell не нужно.

     [Ярлык] --запускает--> [OmniRoute :20128] ----> [Grok]
                                   ^
     [Chatbox] --вопрос/ответ------+   (адрес http://127.0.0.1:20128/v1, модель gc/grok-4.7)

УСТАНОВКА (один раз)
  1. Правый щелчок по omniroute-kit.zip -> Свойства -> внизу галочка "Разблокировать" -> ОК.
  2. Правый щелчок -> "Извлечь всё..." -> впишите папку E:\OmniRoute-Kit -> "Извлечь".
  3. В папке E:\OmniRoute-Kit дважды щёлкните Install-Shortcuts.bat.
     Если Windows спросит "Запустить этот файл?" - нажмите "Запустить".
     Если появится синее окно SmartScreen - "Подробнее" -> "Выполнить в любом случае".
  4. На рабочем столе появятся ярлыки OmniRoute.
  Не перемещайте и не удаляйте папку набора: ярлыки ссылаются на неё.
  Переместили - запустите Install-Shortcuts.bat ещё раз уже из новой папки.

ЯРЛЫКИ НА РАБОЧЕМ СТОЛЕ
  OmniRoute — Запустить        Запускает сервер в свёрнутом окне "OmniRoute - сервер"
                               (в OmniRoute 3.8.52 и новее - в фоне со значком у часов),
                               ждёт готовности, открывает панель в браузере и Chatbox.
                               Окно закроется само (если не было предупреждений).
  OmniRoute — Остановить       Останавливает сервер.
  OmniRoute — Панель (браузер) Открывает панель управления (сервер выключен - запустит).
  OmniRoute — Меню             Все действия: состояние, Chatbox, автозапуск, обновление,
                               диагностика, перенос данных на диск E:, справка "где что искать",
                               повторная попытка режима со значком в трее (пункт 12).
  OmniRoute — Инструкция       Этот файл.

ПЕРВЫЙ ЗАПУСК
  - Сервер стартует в свёрнутом окне "OmniRoute - сервер" (на панели задач) - это окно
    не закрывайте. Холодный старт на Windows может занять 1-3 минуты.
    Режим со значком у часов в OmniRoute 3.8.51 не используется: там OmniRoute ждёт
    запуска только 60 секунд и потом сам останавливает сервер. С версии 3.8.52 агент
    включит значок сам (обновление: Меню -> 8); первый такой запуск - до 7 минут.
  - Агент закрепит папку ваших данных (переменная DATA_DIR), чтобы не "пропали"
    пароль и подключение Grok Build. Если найдутся две папки с базой - агент покажет
    обе и спросит, какая ваша.
  - OmniRoute будет доступен только с этого компьютера (OMNIROUTE_SERVER_HOST=127.0.0.1):
    чужие устройства в вашей Wi-Fi сети не смогут пользоваться вашим Grok Build.
  - Подключить Chatbox: Меню -> 5. Ключ OmniRoute создаётся сам, в Chatbox откроется
    окно "Импорт конфигурации провайдера" - нажмите "Сохранить". Модель: gc/grok-4.7.
  - Запуск вместе с Windows: Меню -> 6 (выключить: Меню -> 7).

ЕСЛИ ЧТО-ТО НЕ ТАК
  - "node.exe не распознано": ярлыки сами обновляют PATH. Если Node.js не установлен,
    поставьте версию LTS (24) с https://nodejs.org и снова нажмите ярлык.
  - Ошибка про политику выполнения скриптов (ExecutionPolicy): ярлыки и .bat запускают
    PowerShell с параметром -ExecutionPolicy Bypass, права администратора не нужны.
    Если файлы всё равно блокируются: правый щелчок по файлу -> Свойства -> "Разблокировать".
  - Сервер долго стартует: подождите минуту и нажмите "Запустить" ещё раз
    (второй экземпляр агент не запускает - он дождётся первого).
  - Если запускаете omniroute вручную - только в НОВОМ окне PowerShell. В окне, открытом
    до первого запуска ярлыка, OmniRoute откроет пустой профиль (пароль CHANGEME,
    нет Grok Build). Закройте такое окно - ваши данные на месте.
  - Нужен доступ к OmniRoute с другого устройства в сети (телефон, ноутбук)? В PowerShell:
      [Environment]::SetEnvironmentVariable('OMNIROUTE_SERVER_HOST','0.0.0.0','User')
      [Environment]::SetEnvironmentVariable('REQUIRE_API_KEY','true','User')
    затем "OmniRoute - Остановить" и "OmniRoute - Запустить". Тогда без ключа sk-... никто
    не сможет пользоваться OmniRoute. Вернуть как было: то же с '127.0.0.1' и 'false'.
  - Обновление (Меню -> 8) сначала проверяет место: нужно около 2 ГБ на диске C:.
  - Всё остальное: Меню -> 9 "Диагностика". Журнал агента: файл agent.log в папке набора.
  - Ваши данные агент никогда не удаляет. При переносе на E: старая папка остаётся копией.

АДРЕСА
  Панель управления:   http://localhost:20128
                       (пароль по умолчанию CHANGEME; сменить: Настройки -> Безопасность)
  Адрес для программ:  http://127.0.0.1:20128/v1   (Путь API: /chat/completions)
  Модель Grok:         gc/grok-4.7
